## 规范

- 只放文档，不放业务配置；配置本体留在仓库根目录。
- 按类型建子目录，编号在目录内局部递增。
- 状态词：已执行 / 待执行 / 参考 / 已过期 / 已废弃。
- `local.conf`、`cache/`、`watch_later/`、`screenshots/` 等设备专属或产物不入库（见 `.gitignore`）。
