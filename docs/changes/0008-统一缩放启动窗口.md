# 0008 统一缩放启动窗口

- 状态：已执行
- 影响范围：`mpv.conf` 中的启动窗口尺寸
- 前置文档：[0007 限制启动窗口最大尺寸](0007-限制启动窗口最大尺寸.md)
- 替代关系：替代 0007 的启动尺寸方案

## 背景与方案

用户澄清需要“小尺寸拉大、大尺寸缩小”。将 `autofit-larger = 60%x60%` 替换为 `autofit = 60%x60%`，启动时保持视频比例，尽可能填满屏幕宽高各 60% 的范围。宽度或高度先达到上限后停止缩放，另一边按视频比例计算。

## 实施

- `mpv.conf`：改用 `autofit`，并更新中文说明。
- `docs/changes/0008-统一缩放启动窗口.md`：记录本次调整及验证事实。
- `docs/README.md`、`docs/changes/README.md`：添加索引并标明 0007 已被替代；保留 0007 正文。

## 后续验证建议

关闭并重新打开 MPV，分别播放小分辨率、大分辨率及不同比例的视频，确认小视频放大、大视频缩小，窗口宽高不超过屏幕相应尺寸的 60%。
