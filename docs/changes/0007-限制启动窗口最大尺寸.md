# 0007 限制启动窗口最大尺寸

- 状态：已执行
- 影响范围：`mpv.conf` 中的启动窗口尺寸上限

## 背景与方案

用户要求按视频原始尺寸启动，同时将窗口最大尺寸限制为屏幕的 60%。原配置使用 `autofit-larger = 90%x90%`，本次将其调整为 `60%x60%`。

保留 MPV 默认的 `window-scale=1`：小视频不主动放大；当视频原始显示尺寸超过屏幕宽度或高度的 60% 时，等比缩小至该范围内。现有配置与脚本未发现其他启动尺寸设置覆盖；`high-quality` 配置仅调整重采样和 HDR 参数，不改变基础窗口尺寸。

## 实施

- `mpv.conf`：将 `autofit-larger` 从 `90%x90%` 改为 `60%x60%`，同步更新中文说明。
- `docs/changes/0007-限制启动窗口最大尺寸.md`：记录本次调整及验证事实。
- `docs/README.md`、`docs/changes/README.md`：添加记录索引。

## 后续验证建议

关闭并重新打开 MPV，分别播放小分辨率和大分辨率视频。确认小视频保持原始显示尺寸，大视频等比缩小且窗口宽高不超过所在屏幕相应尺寸的 60%。
