# 0009 启动窗口居中

- 状态：已执行
- 影响范围：`mpv.conf` 中的启动窗口位置
- 前置文档：[0008 统一缩放启动窗口](0008-统一缩放启动窗口.md)

## 背景与方案

用户希望启动时窗口位于屏幕正中心。在现有 `autofit = 60%x60%` 后添加 `geometry = 50%:50%`，指定水平与垂直位置居中。该写法仅设置位置，保留小视频放大、大视频缩小并保持比例的尺寸行为。

- `docs/README.md`、`docs/changes/README.md`：添加记录索引。
