# 0001 字幕搜索路径与字体名修复

- 状态：已执行
- 类型：变更记录（不可变，后续变化另建文档）
- 生效范围：`mpv.conf`、`input.conf`，以及设备本地 `local.conf`（不入库）
- 环境：Windows + mpv `v0.41.0-dev-g41f6a6450`（`C:\Users\root\scoop\apps\mpv\current`）+ uosc 5.12.0

## 背景

对现有便携配置做逐项检查（解析所有选项、加载脚本、读运行期属性），发现四处「配置写了但实际不生效」的问题：

1. `sub-file-paths` 用 `:` 分隔。mpv 的 path list 在 Windows 上以 `;` 分隔，`:` 不生效。实测解析结果只有一个元素：
   ```
   options/sub-file-paths -> ["sub:subs:subtitle:subtitles"]
   ```
2. `mpv.conf` 末尾 `include = ~~home/local.conf`，但 `local.conf` 从未创建，mpv 每次启动都报错：
   ```
   [0.002][e][file] Cannot open file '.../portable_config/local.conf': No such file or directory
   ```
3. `sub-font` / `osd-font` 写的是 `Maple Mono Normal NF CN`，而本机实际安装的字体族名是 `Maple Mono NF CN`（`C:\Users\root\AppData\Local\Microsoft\Windows\Fonts\MapleMono-NF-CN-*.ttf`，已注册到 HKCU 字体表），名称多一个 `Normal`，libass 找不到即静默回退默认字体。
4. `input.conf` 里 `0`–`9` 先写 `ignore`，随后又整批重新绑定为「数字键固定倍速」，前一组被覆盖，是死代码（实测 keypress `0` 得到的仍是 `set speed 0.5`）。

## 方案

- 平台分隔符：改用 `;`，并在注释中标注 Linux/macOS 需改回 `:`（本仓库跨设备同步，不能假定只有 Windows）。
- `local.conf`：补建一份带注释的设备本地文件（`.gitignore` 已忽略，不入库），既消除启动报错，也给设备专属项（如 `screenshot-directory`）留位置。
- 字体：改成实际族名 `Maple Mono NF CN`，不引入新字体依赖。
- 死绑定：整段删除，不保留「禁用默认数字键」的空注释块，避免误导。

## 实施（改动文件清单）

| 文件 | 改动 |
|---|---|
| `mpv.conf` | `sub-file-paths` 值 `sub:subs:subtitle:subtitles` → `sub;subs;subtitle;subtitles`，并更新注释说明平台差异 |
| `mpv.conf` | `sub-font` / `osd-font`：`Maple Mono Normal NF CN` → `Maple Mono NF CN` |
| `input.conf` | 删除「禁用默认数字键」注释块与 `0`–`9 ignore` 共 20 行 |
| `local.conf`（新增，未入库） | 设备专属配置占位文件，含截图目录示例（注释状态） |

未改动项（属行为偏好，需另行确认）：`uosc.conf` 的 `autohide=no` 与 `cursor-autohide=1500` 不联动；`quit_no_record.lua` 依赖的 `save-watch-history` 未开启；`screenshot-template` 的 `%P` 为播放时间，同帧重复截图会覆盖。

## 执行验证记录

执行环境：Windows，mpv `v0.41.0-dev-g41f6a6450`，通过 `--input-ipc-server` 命名管道在 idle 模式下读取运行期属性并模拟按键。

| 验证项 | 命令 / 方法 | 实际输出 | 结论 |
|---|---|---|---|
| 启动不再报 local.conf 缺失 | `mpv --idle=yes` 后检索日志 | `Reading config file .../local.conf`、`[file] Opening .../local.conf`，无 `Cannot open file` | 通过 |
| 字幕搜索路径生效 | IPC `get_property options/sub-file-paths` | `["sub","subs","subtitle","subtitles"]`（改前为单元素 `["sub:subs:subtitle:subtitles"]`） | 通过 |
| 字体名生效 | IPC `get_property sub-font` / `osd-font` | 均为 `Maple Mono NF CN`；`PrivateFontCollection` 读出的族名同为 `Maple Mono NF CN` | 通过 |
| 输入配置无解析错误 | 启动日志 | `Input config file ... parsed: 59 binds`（删 10 条死绑定后），无解析告警 | 通过 |
| 数字键行为不变 | IPC `keypress 0` | `Set property: speed=0.5` | 通过 |
| Alt+BS 清理命令 | IPC `keypress Alt+BS` | `speed`、`pan`、`contrast` 等全部归零，OSD 输出 `已清除全部播放调整`（无多余引号） | 通过 |

已知限制：

- 字体只验证到「选项值正确 + 系统字体族名匹配 + 注册表注册」，未在真实窗口下用 libass 渲染取样（无桌面截图环境）。
- `;` 分隔符对 Linux/macOS 无效，同步到非 Windows 设备时需改回 `:`（已在配置注释中标明）。

后续验证建议：

- 实际播放一个带 `sub/`、`subs/` 等子目录字幕的视频，确认自动加载生效。
- 观察中文与英文字幕渲染字形是否为 Maple Mono，确认无回退字体。
- 若确认要开观看历史，再补 `save-watch-history = yes` 并评估 `quit_no_record.lua` 的历史清理路径；`state/` 目录需一并加入 `.gitignore`。
