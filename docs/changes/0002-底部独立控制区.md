# 0002 底部独立控制区

- 状态：已执行
- 影响范围：视频播放时的底部进度条、控制按钮与视频显示区域
- 前置文档：无
- 验收状态：最终配置的实机效果由用户验收

## 背景

uosc 的底部进度条和按钮原本叠加在视频上。用户选择独立控制区，而不是自动隐藏：接受视频显示区域缩小，让底部控件不再覆盖视频。

## 方案

- `timeline_persistency=audio,video`：视频播放时常驻进度条，保留原有音频进度条行为。
- `controls_persistency=video`：视频播放时常驻底部按钮。
- 速度控件使用 `speed:1`，高度与控制区一致，避免默认 1.3 倍高度越过控制区上沿。
- 新增独立 Lua 脚本，监听 uosc 的 `user-data/osc/margins`，将归一化底部边距同步给 `video-margin-ratio-bottom`，不写死屏幕像素或窗口比例。
- 不修改捆绑的第三方 uosc 源码，不改变快捷键，不修改上游版本号，不提交或推送 Git。

## 实施

## 后续验证建议

由用户重新启动 mpv 后检查：

1. 普通窗口及全屏播放时，底部进度条与按钮位于视频外。
2. 调整窗口大小、拖动进度条、调整倍速后，控制区与视频布局符合预期。
3. 切换音频或退出播放时没有不期望的画面留边。

- Lua 验证命令：向 `xd://ast_grep` 提交 `{"pat":"mp.observe_property($$$ARGS)","path":"scripts/uosc_video_margin.lua","lang":"lua"}`。
- 实际输出：成功匹配第 5—8 行的属性观察调用，包含匿名函数、局部变量与属性赋值，未报告语法解析错误。
- 配置静态核对：常驻状态使用 uosc 已声明的 `audio`、`video`；`speed:1` 使用现有控件解析器接受的数值缩放参数。
- 验证结论：新增 Lua 主体通过静态语法解析，修改后的配置符合现有格式。
- 已知限制：按照用户最新要求，不再运行播放器；最终配置未进行实机验收。菜单、顶部栏及缩略图预览等浮层行为保持不变，本次仅将底部进度条和按钮移出视频区域。
