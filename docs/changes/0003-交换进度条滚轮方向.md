# 0003 交换进度条滚轮方向

- 状态：已执行
- 影响范围：鼠标悬停 uosc 进度条时的滚轮跳转
- 替代关系：不替代 0002 的独立控制区布局，仅调整滚轮方向

## 背景与方案

用户要求交换进度条的滚轮跳转方向。将 `script-opts/uosc.conf` 的 `timeline_step=5` 改为 `timeline_step=-5`：向上滚动后退 5 秒，向下滚动前进 5 秒。保持步长大小与原有跳转精度不变，不修改第三方源码，不影响音量、倍速等其他滚轮操作。

uosc 在 `scripts/uosc/main.lua` 中通过 `tonumber` 解析步长，支持负数；`scripts/uosc/elements/Timeline.lua` 的上滚处理使用原步长，下滚处理使用相反数。

## 实施

- `script-opts/uosc.conf`：调整步长符号，补充中文方向说明。
- `docs/changes/0003-交换进度条滚轮方向.md`：记录本次调整。
- `docs/README.md`、`docs/changes/README.md`：同步索引。

## 后续验证建议

用户重启 mpv，将鼠标移到进度条，确认上滚后退、下滚前进。

## 执行验证记录

- 执行环境：Windows；使用现有 Bun Eval，仅进行静态配置检查，未启动播放器，未安装依赖。
- 验证命令：Eval 读取 `script-opts/uosc.conf`，检查 `timeline_step` 唯一且符合数值步长格式，并按现有处理器的符号规则计算两个方向。
- 实际输出：`{ timeline_step: '-5', syntax: '通过', wheel_up_seconds: -5, wheel_down_seconds: 5 }`。
- 验证结论：配置格式有效，上下滚轮对应的跳转方向已交换。
