# 0006 添加视频旋转快捷键

- 状态：已执行
- 影响范围：`input.conf` 中的 Ctrl+R 绑定
- 替代关系：无

## 背景与方案

用户希望通过快捷键旋转播放画面。新增 `Ctrl+r cycle-values video-rotate 0 90 180 270`，依次切换 0°、90°、180°、270°，再次按下回到 0°。仅改变播放显示，不修改视频文件；其他快捷键保持不变。

## 实施

- `input.conf`：在窗口与其他操作区域新增 Ctrl+R 绑定及中文说明。
- `docs/changes/0006-添加视频旋转快捷键.md`：记录本次调整。
- `docs/README.md`、`docs/changes/README.md`：同步索引。

## 后续验证建议

用户重启 mpv 后，在播放器窗口中连续按 Ctrl+R，确认画面按预期旋转并能回到原方向。

## 执行验证记录

- 执行环境：Windows，使用现有 Bun Eval，仅静态检查，未启动播放器。
- 验证命令：Eval 读取 `input.conf`，检查 Ctrl+R 绑定唯一、命令及属性名称符合预期、四个角度为互不重复的有效 90° 整数倍。
- 实际输出：`{ key: 'Ctrl+r', angles: [ 0, 90, 180, 270 ], syntax: '通过' }`。
- 验证结论：新增快捷键配置格式有效，现有输入配置中没有重复 Ctrl+R 绑定。
- 已知限制：按用户要求不做实机测试，最终按键交互由用户验收。
