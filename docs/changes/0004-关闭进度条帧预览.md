# 0004 关闭进度条帧预览

- 状态：已执行
- 影响范围：进度条悬停时的画面缩略图
- 替代关系：替代 0002 中保留缩略图浮层的行为；不改变独立控制区布局及 0003 的滚轮方向

## 背景与方案

用户要求关闭进度条上的帧预览。帧预览由 thumbfast 提供，将 `scripts/thumbfast.lua` 更名为 `scripts/thumbfast.lua.disabled`，使其不再作为 Lua 脚本自动加载。脚本正文和 `script-opts/thumbfast.conf` 保留，未改动第三方代码。

uosc 的缩略图初始宽高均为零，只有收到 thumbfast 提供的非零尺寸后才绘制预览；停用 thumbfast 不影响进度条、悬停时间提示、点击跳转或滚轮跳转。

## 实施

- `scripts/thumbfast.lua` → `scripts/thumbfast.lua.disabled`：停用帧预览插件。
- `docs/changes/0004-关闭进度条帧预览.md`：记录本次调整。
- `docs/README.md`、`docs/changes/README.md`：同步索引。

## 后续验证建议

用户重启 mpv 后，将鼠标移到进度条，确认不再显示画面预览，时间提示与跳转仍可使用。若以后需要恢复，将脚本扩展名改回 `.lua` 并重启。

- 执行环境：Windows，仅静态检查，未启动播放器，未安装依赖。

- 实际输出：`Moved to scripts/thumbfast.lua.disabled`，文件内容签名保持不变。
- 验证结论：插件已通过文件扩展名停用，没有新增 Lua 语法变更。
