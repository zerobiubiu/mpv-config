# 0005 缩小进度条高度

- 状态：已执行
- 影响范围：uosc 进度条的纵向高度
- 替代关系：将 0002 使用的进度条高度从 40 调整为 30，其余布局和交互不变

## 背景与方案

用户确认要让进度条变细，而不是缩短横向长度。将 `script-opts/uosc.conf` 中的 `timeline_size=40` 改为 `timeline_size=30`，高度减少四分之一。保持独立控制区、现有按钮大小、滚轮方向和帧预览关闭状态不变。视频留边仍由 uosc 的实际控件高度自动计算。

## 实施

- `script-opts/uosc.conf`：仅调整 `timeline_size`。
- `docs/changes/0005-缩小进度条高度.md`：记录本次调整。
- `docs/README.md`、`docs/changes/README.md`：同步索引。

## 后续验证建议

用户重启 mpv，确认进度条粗细和底部空间占用符合预期。

## 执行验证记录

- 执行环境：Windows，使用现有 Bun Eval，仅静态检查，未启动播放器。
- 验证命令：Eval 读取 `script-opts/uosc.conf`，检查 `timeline_size` 唯一且为正整数字面量。
- 实际输出：`{ timeline_size: 30, syntax: '通过' }`。
- 验证结论：配置数值格式有效，未修改 Lua 正文。
